# Charter r11 宿主功能配置

本次改动保持既有手动压缩与登记表格式。新增自动压缩和登记命令均由维护者显式开启。以下字段放入 Charter 研究 provider 的配置。

```yaml
policyDirectory: /absolute/private/policy
alertsFile: /absolute/private/alerts.jsonl
autoThresholdTokens: 24000
enablePinCommand: true
```

`autoThresholdTokens` 是示例，应根据所用模型、输出预算和实验目标调整。配置后，Agent 每步运行前检查估算 token 数。宿主报告上下文溢出时，在当前轮最多尝试一次恢复。只有压缩成功才请求宿主重试。省略该字段时，仍可用手动 `/compact`。同一会话的压缩锁覆盖事务提交及落盘反查。

## 登记命令

先按实验配置为当前会话建立基线，再在支持宿主斜杠命令的界面中输入：

```text
/charter pin 11 {"effect":"deny","action":["delete"],"resource":"data/raw/**","quote":"Do not delete raw files."}
```

将 11 替换为原始用户消息的实际序号。作用范围和效力由操作者明确填写，`effect` 可用 `deny` 或 `require_confirmation`。省略 `quote` 时，命令只接受含单个文本块的原始用户消息，并使用整个文本块。明确提供 `quote` 时，必须逐字匹配原消息。重复登记同一活动条目不会增加版本。修改会锁定文件并通过原子替换写入下一版本。

策略目录必须是当前会话工作目录之外的绝对路径。部署时还应将其放在 Agent 所有可写根之外，由宿主限制访问。目录位置检查本身无法为同一操作系统身份建立写入隔离。命令参数不写入会话的命令输入记录。

## 摘要与冲突证据

摘要输入只移除已登记的原文片段。同一消息中剩余的任务细节仍会进入摘要，完整约束继续由保护区保存。其他消息中的逐字引用也会移除，转述继续由摘要提示和候选检测处理。

默认保留内置中英文启发式规则。若提供非空的 `conflictPatterns` 字符串数组，则替换默认规则。每项按 Unicode、不区分大小写的正则表达式编译，最多 32 项，每项最多 256 字符。维护者应使用可信且有界的模式。命中会记录规则序号和最多 120 字符的匹配片段。告警日志可能包含原始匹配文字，应留在私有目录，对外导出前脱敏。候选命中用于复核与一次摘要重试。

## 验证与复现

10 项测试、类型检查和构建通过。并发用例在首次压缩已写完事件但落盘等待尚未结束时调用显式区间压缩，验证第二笔事务被拒绝。

在已经配置的隔离 WSL 环境中，从源码根目录运行 `bash research/wsl/wsl-feature-probe.sh`。沿用维护文档的实验目录和专用凭据。试跑验证宿主命令写入 V2、压力触发、事务开始后受控取消、后续轮次恢复和同轮溢出重试去重。证据文件为 `research/wsl/feature-probe-evidence.json`。

溢出由测试探针调用后端入口，取消由探针在收到 start 事件时发出。本次未制造模型服务端真实上下文溢出或操作系统进程崩溃。
