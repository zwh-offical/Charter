# Limitations

- The research backend uses operator-confirmed original user restrictions.
  Tool output is contextual data. Regex screening produces candidates for
  review and can miss semantic conflicts.
- The scoped prompt is a reminder. Enforcement depends on the host. The Windows
  pilot used read-only synthetic tasks and zero model tools. It provides no
  destructive behavior or OS isolation evidence.
- Prior policy versions can remain visible as superseded history. Checkpoint
  protection is explicitly historical.
- Automatic B1 compaction remains disabled. The manual selector keeps the
  latest turn and system prompt. Explicit regions require balanced tool boundaries.
- Post-commit failures are recorded. They require review of the already
  committed transaction and do not provide rollback or a guaranteed request block.
- The storage and request proofs apply to the locked RC, local storage
  implementation and observed DeepSeek route.
